## Rock-Paper-Scissors [Version-2]
A rock paper scissors game with a basic UI, score counter and result decider.
## Objectives
- To create three buttons for rock, paper and scissors, respectively.
- To create a play button.
- To create a game result button.
- To create a score counter.
- To display the chosen options of the user and the computer.
## Learnings
- Managing timings of events.
- Built-in functions such as `Math.number` and `Math.random`.
- Creating loops effectively.
- Using accumulators and counters.
